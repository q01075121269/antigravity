# UI GUIDE: 아덴힐 현장 중심 UI/UX 디자인 가이드

## 1. 기본 원칙 (Tone & Manner)
- 차분하고 직관적인 현장 생산성 도구 중심 UI
- 불필요한 장식보다 빠른 터치와 높은 정보 가독성 우선
- 현장 작업자 화면은 1~2회 터치만으로 보고/대여/출차가 완료되는 극단적 단순성 유지

## 2. 권장 사항 (Do)
- 모바일 우선(Mobile-First) 레이아웃 적용
- 야외 햇빛 아래에서도 잘 보이는 높은 명도 대비 및 큰 터치 영역 확보
- 차량/장비 상태는 명확한 단색 배지(정상: 녹색/무채색, 수리중: 주황, 폐기: 적색)로 표기
- 상태 변경 시 즉각적인 시각적 피드백 제공

## 3. 금지 사항 (Don't - 절대 사용 금지)
- AI 스타일의 과도한 유리 질감(Glassmorphism) 및 네온 글로우 효과 금지
- 보라색 그라데이션 남용 금지 (모노크롬 및 차분한 톤 고정)
- 불필요하게 모든 텍스트를 카드 형태로 감싸는 디자인 금지
- 작은 화면에서 스크롤을 길게 유발하는 복잡한 입력 폼 금지
