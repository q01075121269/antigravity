# PRD: 아덴힐 차량, 장비, 공구 및 주요자재 스마트 통합 관리 시스템

## 1. 프로젝트 목표
- 현장 작업자: 1~2회 터치만으로 출차, 대여, 자재 사용, 고장 신고가 가능한 극도로 단순한 모바일 화면 제공
- 관리자: 자산 가동 현황, 정비 주기, 재고를 실시간 모니터링하고 마스터 DB를 완전 관리(CRUD)하는 PC 관리자 화면 제공

## 2. 핵심 기능
1. 통합 대시보드: 총 자산 수, 수리 중 장비, 점검 임박 차량, 안전재고 미달 자재 현황
2. 장비·공구 이력 관리: 관리번호, 보관위치, 정상/수리중/폐기 상태, AS센터 연락처
3. 차량 관리: 차량번호, 차종, 주행거리, 정기검사일, 보험만료일, 오일/타이어 교체주기 알림
4. 주요자재 관리: 자재코드, 품명, 규격, 현재재고, 안전재고 경고, 입출고 수량 자동 반영
5. 점검 및 수리 이력: 점검일자, 고장/수리 내역, 교체 부품, 비용(원), 차기 점검 예정일

## 3. 사용자 권한 (RBAC)
- 현장 사용자: 차량 출퇴근/반납, 공구 대여/반납, 자재 출고 입력, 고장 신고 (타인 이력 및 마스터 DB 수정 불가)
- 관리자: 4대 자산/자재 마스터 DB 등록·수정·삭제, 권한 관리, 미반납 강제 처리

## 4. MVP 제외 사항 (이번 버전에 안 만들 것)
- 외부 거대 ERP/회계 시스템 자동 연동
- 복잡한 감가상각 자동 정산 공식
- 과도한 시각 효과나 장식 요소 (심플한 모노크롬 유지)
